## Дополнительное задание. Мини-монитор системы
### Что делает программа
Выводит сведения о системе и трижды измеряет память текущего процесса с паузами между измерениями.

### Что нового я узнал о классе Process
Process.GetCurrentProcess() возвращает объект текущего процесса. currentProcess.Id — это PID, currentProcess.WorkingSet64 — память процесса, а Refresh() обновляет данные.

### Сравнение памяти программы и Диспетчера задач
Значения могут немного отличаться, потому что Windows и .NET считают память по-разному. WorkingSet — это физическая память, реально занятая процессом.

### Почему значение памяти может немного изменяться
Во время работы программа выделяет и освобождает память под объекты и буферы, а сборщик мусора .NET периодически её очищает. Поэтому объём не постоянен.
